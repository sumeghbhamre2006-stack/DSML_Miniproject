TITLE OF PROJECT: Credit Risk Prediction System Using Machine Learning
SDG Mapped: SDG 8 (Decent Work & Economic Growth) & SDG 9 (Industry, Innovation & Infrastructure)
Abstract:
Automated credit risk assessment is critical for FinTech lending platforms to reduce loan defaults and make rapid, objective lending decisions. This project builds a machine learning-based credit risk scoring system using historical LendingClub loan records. Data preprocessing included handling missing values, encoding borrower demographics, scaling financial indicators, and addressing default class imbalance. Three supervised classifiers—Logistic Regression, Decision Tree, and Random Forest—were trained and evaluated using Accuracy, Precision, Recall, and ROC-AUC metrics. Random Forest achieved the best overall discrimination (ROC-AUC 0.732, Recall 0.668), prioritizing the detection of potential defaulters. A clean, interactive Streamlit GUI allows loan officers to input applicant financial profiles, select models dynamically, and instantly view risk probabilities alongside color-coded approval decisions (Approve, Review, Reject).
Objectives:
  1. To clean and preprocess historical loan records by handling missing values, encoding categories, and handling class imbalance.
  2. To implement and train three machine learning models: Logistic Regression, Decision Tree, and Random Forest.
  3. To benchmark and compare model performance using Accuracy, Recall, F1-score, and ROC-AUC metrics.
  4. To develop a simple, interactive Streamlit GUI for real-time applicant risk evaluation and loan decision assistance.
Dataset:
  • Type of dataset: Tabular Financial Loan Records (CSV)
  • Source: LendingClub Loan Dataset (accepted_2007_to_2018Q4.csv)
  • Attributes: loan_amnt, term, int_rate, grade, emp_length, home_ownership, annual_inc, purpose, dti, fico_range_low, loan_status

Software (Front, Back): Streamlit (Front-end), Python 3.12 (Back-end)

Library: scikit-learn, pandas, streamlit, matplotlib, pickle

Functions Used: train_test_split(), StandardScaler(), fit(), predict_proba()

Machine Learning Algorithm: Logistic Regression, Decision Tree, Random Forest
